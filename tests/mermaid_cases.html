Mermaid verdicts

Re-records mermaid_cases.json, which test_validate_agrees_with_mermaid holds validate to. Serve the repo root (python -m http.server) and open /tests/mermaid_cases.html. It renders every case with the Mermaid that prx.py pins (PAGE_MERMAID), lists the verdicts that changed, and prints the file to save. A box whose id isn't a whole word of the source is "stray" (Mermaid split some text into it, or glued it to an arrowhead). A recorded "blank" or "stray" is kept while Mermaid still draws the diagram, since some strays are whole words (-. a.-b .->): check those by eye.
